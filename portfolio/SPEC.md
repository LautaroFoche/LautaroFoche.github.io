# SPEC.md - Requisitos del Portfolio

## 1. Objetivo
Crear un portfolio web profesional para Lautaro Fochesatto, Data Engineer Junior y Analista de Datos de Córdoba, Argentina.

## 2. Público Objetivo
- Recruiters tecnológicos
- Equipos de Data Engineering
- Consultoras de datos
- Empresas buscando perfiles junior con experiencia en cloud y migraciones

## 3. Requisitos Técnicos
- HTML semántico
- CSS organizado con variables
- JavaScript mínimo
- Sin backend
- Sin librerías de animación
- Sin dependencias innecesarias
- Responsive desde 360 px
- Navegable con teclado
- Foco visible
- HTML semántico
- Contraste legible
- Respeto por prefers-reduced-motion
- Sin scroll horizontal
- Sin botones falsos ni enlaces vacíos

## 4. Estructura del Sitio
1. Header con navegación
2. Hero: Nombre, título, presentación, botones
3. Sobre mí
4. Experiencia destacada
5. Stack tecnológico
6. Sección "Cómo trabajo" / Áreas de experiencia
7. Educación e idiomas
8. Contacto
9. Footer

## 5. Navegación
- Inicio
- Sobre mí
- Experiencia
- Tecnologías
- Contacto

## 6. Privacidad
- No publicar teléfono hasta confirmación
- Email como marcador "Pendiente de confirmación" en fase inicial

## 7. Accesibilidad
- Responsive desde 360 px
- Navegable con teclado
- Foco visible
- HTML semántico
- Contraste legible
- Respeto por prefers-reduced-motion
- Sin scroll horizontal
- Sin botones falsos ni enlaces vacíos
- No presentar tecnologías con porcentajes ficticios
- No usar barras de progreso para habilidades
- Animaciones breves y opcionales

## 8. Explorador de stack e identidad de pipeline

- Hero con flujo ilustrativo y roles diferenciados de fuente, plataforma, transformación, consumo y orquestación.
- Stack desplegable en una composición inspirada en star schema; centro «Mi stack».
- Seis grupos: orquestación e integración, transformación, lenguajes, bases de datos y warehouse, analytics y BI, desarrollo y entorno.
- Ícono local y nombre legible para cada una de las trece tecnologías.
- Botón de apertura/cierre y selección de categoría con explicación y conexión destacada.
- El enlace de navegación y la carga directa de `#tecnologias` abren el explorador.
- Estrella desde 1100 px, dos columnas entre 700 y 1099 px y árbol vertical por debajo de 700 px.
- Contenido disponible sin JavaScript; teclado, foco y movimiento reducido preservados.
- Sin métricas simuladas, nuevas afirmaciones profesionales ni dependencias de producción.

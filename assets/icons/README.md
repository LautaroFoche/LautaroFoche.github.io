# Íconos locales

Los logotipos de Apache Airflow, dbt, Python, Oracle, Microsoft SQL Server, Snowflake, Power BI, Tableau, Git, GitHub y Docker proceden de [Simple Icons 11.15.0](https://github.com/simple-icons/simple-icons/tree/11.15.0/icons). Se conserva su geometría y se aplica un color para su presentación. Licencia CC0 incluida en `LICENSE-simple-icons.md`; las marcas pertenecen a sus respectivos titulares.

`sql.svg` y `azure-data-factory.svg` son pictogramas propios de base de datos y fábrica, respectivamente; no pretenden ser logotipos oficiales. Todos se sirven localmente, sin servicios externos en tiempo de ejecución.
